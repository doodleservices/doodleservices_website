## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/doodleservices/doodleservices_website.git
   cd doodleservices_website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000).

---

## 🚢 Production Build & Deployment

To create an optimized production build locally:

```bash
npm run build
npm run start
```

### Continuous Deployment (CI/CD)
The project is connected to **GitHub** and deployed on **Vercel**. Every push to the `main` branch automatically triggers an instant production deployment with SSL verification:
